# 이븐쇼핑 정밀 — 36편 전수 칼 카피 판

링크를 받아서 **이븐쇼핑과 같은 화면·같은 화법·같은 목소리·같은 호흡**의
9:16 쇼츠를 완성해 놓는 것이 이 스킬의 전부다.

원본 채널을 **최근 36편 연속(2026-08-06 ~ 09-09)** 내려받아 픽셀·밀리초 단위로
잰 값으로 세웠다. 짐작이 아니라 실측이다.

## 0. 절대 어길 수 없는 것

1. **`plan.voice_narr` 에 목소리 ID를 반드시 넣는다.**
   빼먹으면 렌더러 기본값(205Hz 여성)으로 구워져 원본과 완전히 달라진다 —
   원본은 **152Hz 남성**이다. 「칼 카피는 목소리까지」다.
   렌더 로그에 **「목소리 갈아 끼움」** 줄이 찍히는지 눈으로 본다.
2. **말속도는 8.8자/초다.** 27초 편이면 대본이 **235자** 안팎이어야 한다.
   길면 TTS 속도를 올려 맞추지 말고 **문장을 줄인다.**
3. **소재는 움직이는 영상이다.** 정지 이미지 슬라이드쇼로 만들면 이 채널이 아니다.
4. **링크 하나로 만들지 않는다.** 다른 소스를 **최소 3개 더** 찾아 조합하고
   컷 순서를 바꾸고, 좌우반전·크롭·색보정으로 지문을 벗긴다.
   원본과 구성까지 같으면 중복 콘텐츠로 읽혀 수익창출이 거절된다.
5. **인트로 카드에도 멘트가 깔린다.** 36편 모두 0.04초에 목소리가 시작한다.
6. **효과음을 넣는다.** 컷 전환 클릭 + 강조 4~6발 + 인트로/마무리.
7. **원본 현장음을 살린다** (`volume=0.12`). 제품 소리가 설득력이다.
8. **실존 제품이다. AI 생성 이미지 금지.**
   없는 걸 지어내면 소개가 아니라 거짓이 된다.
9. **박힌 자막을 화면에 남기지 않는다.** 크롭으로 피하지 말고 지운다 — 3-1 참고.
10. **껍데기는 `shop`** — 가짜 앱 헤더. 로고 자리에 **자기 채널명 넉 자**를 넣고
    **원본 채널명 «이븐쇼핑»은 쓰지 않는다.**
11. 9:16 / 1080×1920 고정.
12. 중간에 "이렇게 할까요?" 하고 묻지 않는다. 애매하면 기본값으로 민다.

| 항목 | 기본값 |
|---|---|
| 껍데기 | `shop` — 가짜 앱 헤더 + 로고 넉 자 |
| 지표 줄 | `조회수 235만 \| 댓글 697개` — **36편 고정값. 바꾸지 않는다** |
| HL2 색 | `#01FEF6` |
| 길이 | **26~30초**, 자막 블록 **26~30개** (초당 1블록) |
| 대본 글자수 | **길이 × 8.8자** (27초 → 235자) |
| 한 자막 | **7~11자**, 1줄 |
| 컷 | 자막 블록의 **1.2~1.4배** + 인트로 카드 안에 2~4개 |

| 최종 소리 | 컴프레서 → `loudnorm I=-13.5:TP=-1.0:LRA=2` |
| 파일명 | `<한글 제목>_v001.mp4` — 영문 slug 쓰지 않는다 |

## 3. 진행 순서

### 3-1. 소재 — 링크 하나로 만들지 않는다

받을 수 있는 링크: 유튜브 쇼츠, 인스타 릴스, 틱톡, 판매 페이지.
**같은 제품을 다룬 영상을 원본 포함 최소 4개** 모아 컷마다 출처를 갈아 끼운다.
사용자가 링크를 하나만 줘도 **되묻지 말고 더 찾아** 채운다.

```powershell
$w = 'work\<slug>'
New-Item -ItemType Directory -Force $w | Out-Null
$links = @('<링크1>','<링크2>','<링크3>','<링크4>')
for ($i = 0; $i -lt $links.Count; $i++) {
    yt-dlp -f 'bv*[ext=mp4]+ba[ext=m4a]/b' -o ("$w\s{0:d2}.%(ext)s" -f $i) $links[$i]
}
```

**섞는 요령** — 같은 동작을 다른 각도로 잡은 클립 둘을 이어 붙이면 원본 어디에도
없는 컷이 된다. 전반부와 후반부의 주 출처를 아예 다른 영상으로 잡는다.
한 소스가 전체의 절반을 넘지 않게 한다.

**박힌 자막이 있으면** — 크롭으로 피하면 제품이 화면 구석으로 밀린다.
순서는 ① 자막 없는 깨끗한 소스를 찾는다 ② 못 찾으면 인페인팅으로 **글자 획만**
지운다 ③ 띠가 가장자리면 통째로 잘라낸다 ④ 그래도 남으면 그 자리에
우리 자막을 얹어 덮는다. `delogo` 는 사각형을 통째로 뭉개 커튼 자국이 남으므로
쓰지 않는다.

### 3-2. 대본

[references/대본작법.md](references/대본작법.md) 의 **여덟 칸**으로 쓴다.
**제품형인지 활용법형인지 먼저 정하고**, **인트로 카드 문구(HL1 / HL2)를 먼저
정한다** — 그게 곧 유튜브 제목이다.

한 편에 반드시 들어가는 것:

| 칸 | 고정 문구 | 위치 | 원본 편수 |
|---|---|---|---|
| 1 | **`최근`** (주로 `최근 딱 봤을 때는 ○○처럼 생긴 이 제품이`) | 7% | **36/36** |
| 2 | `SNS` + `바이럴이 폭발하며` → **`~다는데`** | 19~24% | 33/36 |
| 3 | **`이건 바로 <제품명>`** | 31% | 33/36 |
| 4 | **`이게 말도 안 되는게`** … **`~다는 거`** | 36% | 33/36 |
| 5 | `심지어` · `우선` | 60% | 16/36 |
| 6 | **`근데 진짜 충격적인 포인트는`** | **79%** | **36/36** |
| 7 | **`~다고`** / **`~라고`** | 99% | 36/36 |

칸 1 과 칸 6 은 36편이 하나도 빠짐없이 갖고 있다. 빼면 다른 채널이 된다.

**칸 3(정체 공개)과 칸 7(마무리)에 제일 좋은 화면을 붙인다** — heatmap 27편에서
되감아 본 구간이 그 둘뿐이었다.

### 3-3. plan.json

`work\<slug>\plan.json` 에 쓴다. 전체 예시는
[references/plan_example.json](references/plan_example.json).

| 필드 | 뜻 |
|---|---|
| `shell` | **`shop`** — 이 프리셋은 가짜 앱 헤더가 정체다. 바꾸지 않는다 |
| `logo` | 헤더 워드마크. **넉 자**여야 실측 자간(폭 457)이 산다 |
| `metrics` | 36편 고정값. 바꾸면 폭이 달라져 정렬이 흔들린다 |
| `hl2_color` | **`#01FEF6`** |
| **`voice_narr`** | Typecast 목소리 ID. **빼면 기본 목소리로 구워진다** |
| `voice_punch` | 안 주면 기본 PUNCH |
| `crop_y` | 컷의 세로 크롭 위치. 안 주면 중앙 |
| `intro_cuts` | 카드 2초 안에서 갈아 끼울 컷 **2~4개** |
| `src2`/`ss2` | 그 블록 **한가운데서 컷을 한 번 더** 바꾼다 (컷/블록 1.2~1.4배용) |
| `voice` | `NARR`(기본) 또는 `PUNCH` |
| `sfx` | `click` `pop` `ding` `hit` `boing` `fail` `swoosh` `drum`. 편당 4~6개 |
| `mute_source` | `true` 면 소스 현장음을 죽인다 (원본에 사람 나레이션이 깔린 경우) |

### 3-4. 렌더

```powershell
python scripts\evenshop_render.py --work work\<slug>
```

**경고가 뜨면 굽지 말고 `plan.json` 을 고친다** —

- 블록 평균 길이가 0.84~1.03초 밖 → 대본 길이를 고친다
- 컷/블록 비율이 1.2 미만 → `src2` 로 컷을 더 쪼갠다
- 인트로 컷이 1개 → `intro_cuts` 를 2~4개로 채운다
- **"박힌 자막을 다 밀어낼 수 없다"** → 그 소스의 다른 구간을 쓰거나 소재를 간다

굽고 나서 **채널규격 10번 검수 체크리스트**와 대조한다. 특히 —
**말속도 8.8자/초 · 최종 −13.5 LUFS / LRA 2 이하.**

### 3-5. 업로드용 제목·해시태그

- **제목 = 인트로 카드 문구(HL1 + HL2), 물음표 빼고.**
  제품명을 넣지 않는다. 17~24자.
- **해시태그 = 제품명 계열 2~4개 + 마지막은 반드시 `#꿀템`.** 총 3~5개.
  영상 자막에 제품명을 안 박으므로 **검색 유입은 전부 해시태그가 맡는다.**
